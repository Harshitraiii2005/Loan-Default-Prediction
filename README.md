# Loan Default Prediction - Streamlit App

## 🚀 Overview
This project aims to predict whether a borrower will default on a loan using machine learning models. The web application is built using **Streamlit** with an interactive and modern 3D UI.

## 📌 Features
### 🎯 1. Home Page
- Overview of loan default prediction.
- Recent loan default trends and statistics.

### 📊 2. Loan Risk Prediction
- Users can enter details like income, loan amount, credit score, etc.
- Predicts the probability of loan default using a trained ML model.

### 📈 3. Data Visualization & Analytics
- Interactive graphs and insights into loan default trends.
- Feature importance analysis to understand key risk factors.

### ⚡ 4. Explainability Dashboard
- SHAP values to explain why a loan is classified as risky or safe.
- Helps users understand the prediction logic.

### 🏦 5. Real-time Loan Assessment
- Uses the best-performing model to assess loan risks instantly.
- Supports real-time updates with new data.

## 🔧 Installation & Setup
### 1️⃣ Clone the repository:
```bash
git clone https://github.com/Harshitraiii2005/Loan-Default-Prediction.git
cd Loan-Default-Prediction
```

### 2️⃣ Install dependencies:
```bash
pip install -r requirements.txt
```

### 3️⃣ Run the Streamlit App:
```bash

```
